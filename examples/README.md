# Examples · 模板使用说明

## template.html

通用 9 模块预览稿模板。**所有内容都是 `[xxx·待客户提供]` 占位**，没有客户真实信息——可以直接拿去用，或者基于它改造。

### 怎么用

1. **复制**：`cp template.html my-project.html`
2. **替换占位**：把 `[xxx·待客户提供]` 换成真实内容
3. **条件模块处理**：
   - 模块 5（参考视频）：用户没给参考片源就**整个 module 删除**
   - 模块 8（权益占位图）：用户没给权益内容就**整个 module 删除**
4. **部署**：`workbuddy_cloudstudio_deploy` → 拿到分享链接 → 发给客户

### 9 模块位置速查

| # | 模板里的 class | 用途 |
|---|---|---|
| 1 | `.hero` | 项目卡片（首屏视觉） |
| 2 | `.one-liner` | 创意一句话（大字标语） |
| 3 | `.form-table` | 形式说明（表格） |
| 4 | `.role-grid` | 角色设定（双角色卡片） |
| 5 | `.ref-video` | 参考视频（条件模块） |
| 6 | `.flow` | 叙事流程图（横向步骤） |
| 7 | `.shot-table` | 分镜简版（表格） |
| 8 | `.benefit-grid` | 权益占位（卡片） |
| 9 | `.checklist` | 待确认项（勾选框） |

### 配色

模板默认是深绿（`#2d5016`），适合银行/政企/文旅类。如果客户品牌色不同：
- 改主色：`grep -n "2d5016" template.html` 全部替换
- 改辅助色：`1a3009`（深绿）、`e8f5e9`（浅绿）、`f5f5dc`（米色）三处
- 推荐主色：金融用蓝绿系、政企用红金系、文旅用绿米系、科技用深蓝系
